## Pertemuan 5 - Latihan WPF Membuat Dashboard

### Deskripsi

Pertemuan ini mengenalkan pembuatan aplikasi desktop menggunakan **Windows Presentation Foundation (WPF)**. Pembelajaran mencakup pembuatan desain antarmuka menggunakan **XAML** serta implementasi logika aplikasi menggunakan **C#**.

Pada latihan ini dibuat **Student Registration App**, yaitu aplikasi desktop sederhana yang digunakan untuk mencatat dan menampilkan data pendaftaran mahasiswa.

### Struktur Project

```text
StudentRegistrationApp/
├── App.xaml
├── MainWindow.xaml
├── MainWindow.xaml.cs
├── StudentRegistrationApp.csproj
└── ...
```

Aplikasi berhasil dibuat dalam bentuk desktop application menggunakan WPF dengan tampilan dashboard dan fitur pencatatan data pendaftaran mahasiswa.
